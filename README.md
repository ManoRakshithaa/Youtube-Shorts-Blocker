# YouTube Shorts Blocker

A free Chrome extension that hides YouTube Shorts from your feed and redirects Shorts URLs to the normal video player. This disables the addictive vertical scrolling mechanism and lets you watch videos in the standard interface (avoiding doom scrolling)

## What it blocks
- Shorts shelf on the YouTube homepage
- Shorts video cards in search results
- Direct navigation to /shorts/ URLs (redirects to normal player)

## How to install (FREE — no Web Store needed)

1. Download or clone this folder onto your computer.
2. Open Google Chrome: Go to chrome://extensions/
   Brave Browser: Go to brave://extensions/
   Microsoft Edge: Go to edge://extensions/
3. Turn on **Developer mode** (toggle in the top-right corner).
4. Click **"Load unpacked"**.
5. Select this `youtube-shorts-blocker` folder.
6. Done! The extension is now active. 🎉

## Is it safe?
Yes. This extension:
- Requires zero permissions (it doesn't access your data, history, or passwords)
- Runs only CSS/JS on YouTube pages
- Never connects to any server
- Is fully open-source — you can read every line of code
